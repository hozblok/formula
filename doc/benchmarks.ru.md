# Бенчмарки

Замеры скорости для `formula`, каждый в отдельном файле с кодом для воспроизведения,
окружением и датой.

- [Сырая арифметика против поля](benchmark-raw-arithmetic.ru.md) — одно умножение
  против `gmpy2`, `decimal`, `mpmath` при согласованном числе десятичных знаков.
- [Трансцендентные функции](benchmark-transcendentals.ru.md) — реальная цена высокой
  точности — это `sin`, а не умножение (~100x отставание от `mpmath` на базе `gmpy2`).
- [Сквозной тест против SymPy](benchmark-end-to-end-sympy.ru.md) — разобрать строку,
  получить значение и производную в точке до N знаков.
- [Масштабирование cpp_dec_float](benchmark-dec-float-scaling.ru.md) — как тип Boost
  масштабируется с точностью; данные, лежащие в основе потолка лестницы.

Обоснование дизайна, использующее эти числа:
[лестница точности](precision-ladder.ru.md).
